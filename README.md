# 📘 Java Fundamentals

<img src="https://img.shields.io/badge/Java-007396?logo=openjdk&logoColor=white" alt="Java"> <img src="https://img.shields.io/badge/JUnit-25A162?logo=junit5&logoColor=white" alt="JUnit"> <img src="https://img.shields.io/badge/lessons-12%20topics-blue" alt="12 topics">

A structured, ground-up study of **core Java**, built up lesson by lesson during the Intec
*Java Developer EE* programme. Each topic lives in its own folder, from basic syntax through
OOP to exceptions and I/O.

> 🇳🇱 Een gestructureerde studie van de **Java-basis**, les per les opgebouwd tijdens de
> Intec-opleiding *Java Ontwikkelaar EE*. Elk onderwerp staat in een eigen map — van basis­syntax
> over OOP tot excepties en I/O.

## ▶️ Run

Requires **Java 17+**. Open the project in your IDE and run any topic's example class, or run
the tests with your build tool.
